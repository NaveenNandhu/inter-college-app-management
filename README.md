# Inter-College Meet Management System

A full-stack web application designed to simplify and digitize the management of inter-college meets, technical symposiums, cultural events, and student competitions.

This platform helps colleges manage:
- Events
- Student registrations
- QR-based entry systems
- Certificates
- Lunch token distribution
- Coordinator management

---

# 📌 Project Overview

Managing inter-college events manually creates many challenges such as:

- Paper-based registrations
- Manual attendance tracking
- Event coordination confusion
- Food token misuse
- Delayed result announcements
- Difficulty generating certificates

This project solves these problems using a digital event management platform with QR-based automation.

---

# ✨ Key Features

## 👨‍💼 Admin Module
- Create and manage inter-college meets
- Add multiple events under a meet
- Assign coordinators for events
- View registered participants
- Manage event schedules and venues
- Send notifications and greetings

## 🎓 Student Module
- Student registration & login
- Browse available events
- Register for events online
- View registered events
- Download QR codes for participation

## 📱 QR-Based Event Entry
- Unique QR code generated for every registration
- Coordinators can scan QR codes
- Attendance automatically recorded
- Reduces manual verification

## 🍱 Lunch Token System
- Students registered for events receive lunch QR
- Prevents duplicate food collection
- Simplifies food distribution

## 🏆 Result Management
- Event coordinators can update results
- Students receive result notifications

## 📜 Digital Certificate Generation
- Automatic participation certificate generation
- Certificates delivered digitally
